Topics Hub with Timeback Machine™

Your Claude chats and files pile up fast. Topics Hub files them under the subjects you keep coming back to, so you can find anything again. Every day, Timeback Machine™ looks at your new work, suggests a hub when a subject keeps coming up, and suggests ways to automate work you keep repeating, with an estimate of the hours it would give back. Nothing happens until you approve it.

How it works

Files your work

Every artifact, and every chat that belongs to a subject, becomes a card under the topics it belongs to. Anything that fits nowhere waits in Unsorted.

Builds topic hubs

When a subject comes up again and again, it suggests one page that pulls your decisions, facts, open questions and sources together, and keeps it current.

Gives time back

When you keep repeating the same work, it suggests a fix, estimates the hours a week it would save, and shows the chats that prove it.

Asks first

Every suggestion waits for Yes, Not now or Never. It never deletes anything and only reads the sources you allow.

Install it in Claude

Setup takes about ten minutes, most of it Claude reading your recent work. You need a paid Claude plan.

Install in Claude Open in the Claude desktop app
  1. Claude opens with the install message already typed. Claude shows a caution note above any message that arrives from a link, which is normal. Read the message, then press Enter.
  2. Answer Claude's four short questions: your name, your time zone, when the daily check should run, and which sources it may read.
  3. When Claude asks permission to set up your page or the daily check, click Allow.

If the message box comes up empty, click Copy the install message, paste it into a new Claude chat and press Enter. Prefer to set it up by hand? Download the manual install.
