TOPICS HUB WITH TIMEBACK MACHINE™: INSTALL INSTRUCTIONS FOR CLAUDE

You are setting up Topics Hub with Timeback Machine™, version 1.1, for me. I started this install from the Doovli page and asked you to follow these instructions. Topics Hub files my Claude work under the subjects I keep coming back to, so I can find things again. Timeback Machine™ is its daily check: it files new work, suggests a topic hub when a subject keeps coming up, keeps those hubs current, and suggests ways to automate work I keep repeating. It only suggests. I approve everything on the page.
Work through the steps in order. Ask me questions only in Step 1 and Step 5, and stop for my answer only where the steps say to. Write to me in plain language, with no em dashes.

STEP 0. Get the files
Download these two files with your code tools, for example curl in your computer environment. Do not use a web reader that summarizes pages, because you need both files complete and unchanged:
- https://raw.githubusercontent.com/RevCeleris/topics-timeback/main/topics.html (the page)
- https://raw.githubusercontent.com/RevCeleris/topics-timeback/main/tasks/daily.txt (the task text)
Check that topics.html contains const APP_VERSION="1.1" and that daily.txt contains the heading DAILY. Then go on to Step 1.
If you cannot download both files complete, tell me in one sentence, and ask me to download the package from https://doovli.app/topics-hub.html (the Manual install link), unzip it, and attach "Topics Hub with Timeback Machine - Setup Prompt.docx" and "Topics Hub with Timeback Machine.html" to this chat. When I do, follow the attached Setup Prompt file instead of this one.

Rules for everything you write
- State only what a chat, item or source supports. Never invent a date, a count or a fact.
- Skip personal, medical, financial account and family matters. Never put them on a card, topic or suggestion.
- Describe work and processes, never people. Never record or report when or how long I worked.
- Write in plain, connected sentences with no em dashes and no buzzwords.

STEP 1. Ask me first
Open with one friendly sentence: "Let's set up your Topics Hub. Four quick choices, then I do the rest, which takes about ten minutes." Do not report file downloads or checks unless something failed.
Then ask the four questions below. If you have a tool that shows me clickable choices (often called ask_user_input or AskUserQuestion), use it, one question per card, with the default as the first choice and labeled (default), so I can answer with clicks. Otherwise, ask them as a short numbered list and tell me I can reply with just the numbers I want to change, or "defaults" to accept all of them.
1. Page name. Choices: my first name from my Claude profile (default), or type another.
2. Time zone. Choices: the time zone my messages show (default), or type a city.
3. Daily check time. Choices: 3 PM (default), 9 AM, 12 PM, 6 PM.
4. Extra sources. Besides my Claude chats and artifacts, may Timeback Machine™ also read my email, calendar or Google Drive? Offer only the ones connected here. Choices: none, chats and artifacts only (default), or any of the connected ones (allow more than one).
Treat a blank answer as the default and go on.

STEP 2. Publish my page
Publish topics.html, the file you downloaded in Step 0, as a new artifact titled "[my name] - Topics Hub". Publish the file exactly as downloaded, using your artifact tool's option to publish from a file if it has one. Do not edit, shorten, retype or restyle it.
Give the page these capabilities, declaring them if your artifact tool asks for that:
- Database: one database. Anyone I share the page with can read it, and only I can write to it (rule: path "", read "view", write "owner").
- User: the page knows who is signed in.
- Sample: the page can ask Claude directly. It uses this for its search box.
- Connectors: the scheduled-tasks connector, with the tool fire_trigger (it may be named "Claude Code Remote"). The page uses it for its Yes and Update now buttons.
If one capability is not available to me, publish the page anyway and tell me in one sentence which feature will not work. Pin the page to my sidebar if your tools allow it. Keep the link to the published page. The task text calls it {{TOPICS_URL}}.

STEP 3. Save my settings
Use the artifact data tools (named ArtifactData in some sessions, and db_get, db_list and db_write in others; load them via ToolSearch if needed) with my page link for every write. Write settings/main: name, timezone (as I said it), timezoneIana (the IANA name, such as America/Chicago), dailyTime, timeback true, sources (the sources I allowed, as a short list), and priorInventionsUrl.
For priorInventionsUrl: list my artifacts. If one is a web page whose title ends in "Prior Inventions", use its link. Otherwise leave it blank. The page shows Prior Inventions buttons only when this is set.

STEP 4. First look at my work
Before you start, tell me in one sentence that this first look can take a while if I have a lot in my Claude account, and that I can leave this tab open and come back.
This first look is what I will see when I open the page, so be thorough. Follow DAILY in the task text (daily.txt, downloaded in Step 0), steps 1, 2, 4 and 5, with these changes:
- Look back 90 days instead of to the last run: list my artifacts, and search and list my chats as far back as your tools reach in that window. Note how far back you got.
- In step 1, file every artifact as a card and give it the topics it belongs to. Create topic names as you need them: short, plain names a person would use, such as "Home remodel" or "Board reporting". Use no more than 12 topics; put the rest under Unsorted by leaving topics empty.
- In step 2, suggest up to 5 hubs, strongest first. Do not build any hub yet.
- In step 4, suggest up to 3 Timeback Machine™ fixes, the clearest first.
Then write meta/sync with lastRun (for example "today at 3:04 PM") and a one-line summary.
Send me a short message with: the link to my page; how many items you filed and under how many topics; how many hubs and Timeback Machine™ fixes you suggest; how far back you looked; and what to do next: open the page, look at Suggestions, and press Create hub, Not now or Never on each.

STEP 5. Turn on the daily check
Ask me first, in one short message: "Turn on Timeback Machine™'s daily check? It runs every day at [my time], files new work, keeps your hubs current and brings you new suggestions. It also makes the Yes and Update now buttons on your page work. Reply yes." Wait for my answer.
If I say yes, create a scheduled task named "Timeback Machine" that runs every day at the time I chose, moved a few minutes off the hour (3:04 PM for 3 PM), in my time zone, with push notifications on. Use the complete text of daily.txt as its instructions, with every {{NAME}} replaced by my name, {{TIMEZONE}} by my time zone, {{TOPICS_URL}} by my page link and {{SOURCES}} by the sources I allowed. Give it access to my artifact data, the scheduled-tasks connector and past-chat search, plus only the connectors I allowed in Step 1. Turn off every other connector for this task.
Write the task ID to my page as settings/tasks: {daily: the task ID}. Also write settings/update: {installed: "1.1"}.
If I say no, or you cannot create scheduled tasks here, tell me that my page will not update on its own, and that I can come back to this chat any time and send "Turn on the daily check".

STEP 6. Finish
Send me three short lines on how to use the page: Suggestions is where Timeback Machine™ asks before doing anything; drag a card onto a topic, or tick several cards, to file or archive them; and the search box answers questions about my work. End with the page link.
